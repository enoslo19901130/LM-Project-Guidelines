# LM-Project｜客戶端契約研究與藍隊防禦筆記

這是 **LM-Project** 的獨立靜態閱讀包，不是原系統的官方文件，也不是對第三方系統完成滲透測試的報告。內容從受控的本地客戶端樣本、可取得的靜態資產、自建隔離服務端及測試流量整理二進位協定與狀態契約；既有唯讀封包紀錄若用作對照，會與自建環境實測分開標示。以紅側「本地契約可能被復原到哪一步」的學習視角，提出藍側的驗證與可觀測性檢查。

**資料邊界：未入侵、直接操作或擷取原系統後端資料庫。** 文中資料庫查詢、寫入、角色狀態與防禦實驗均指**自建測試環境**；不能據此推論第三方系統的資料庫狀態或安全水位。建議的差異測試與控制項不等於已執行的對外攻擊或已部署的防線。

閱讀時請區分**本地實測／靜態證據**、**根據證據作出的推論**和**尚待驗證的防禦建議**。特定數值和欄位語意只適用於其來源樣本，不自動延伸到其他版本或其他系統。

## 手機與離線閱讀

- 五頁都有行動版 viewport 和響應式樣式；手機直向閱讀時，寬表格和程式碼區塊可在**區塊內左右滑動**，正文不需要整頁橫向拖移。
- 直接開啟 `index.html` 即可離線閱讀；頁面使用內嵌 CSS、原生 HTML，無外部字型或 CDN 相依。也可只在本機預覽：

  ```sh
  python -m http.server 8000 --bind 127.0.0.1
  ```

  接著開啟 `http://127.0.0.1:8000/index.html`。此命令只供本機靜態預覽，**不連接遊戲服務或資料庫**。
